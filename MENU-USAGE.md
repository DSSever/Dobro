# ✅ Единое меню для всех страниц

Система единого меню полностью настроена! Все страницы теперь используют одно меню, которое загружается автоматически.

## 📁 Структура файлов меню:

- **menu.html** - HTML структура хедера и меню
- **menu.css** - Все стили для хедера и меню  
- **menu.js** - JavaScript логика загрузки и функциональность меню

## ✨ Преимущества:

✅ **Единая правка** - Смените меню в menu.html, и оно обновится на всех страницах
✅ **Простота редактирования** - Больше не нужно обновлять хедер на каждой странице
✅ **Консистентность** - Гарантирует одинаковое меню на всех страницах
✅ **Легкое обслуживание** - Все стили и логика в одном месте

## 📝 Как редактировать меню:

### Изменить структуру меню:
Откройте **menu.html** и отредактируйте:
- Логотип
- Города в выпадающем списке
- Ссылки на страницы
- Текст кнопок

### Изменить внешний вид:
Откройте **menu.css** и измените:
- Цвета, шрифты, размеры
- Адаптивность
- Анимации и переходы

### Изменить функциональность:
Откройте **menu.js** и измените:
- Логику закрытия меню
- События при клике
- Загрузку меню

## 🔄 Как работает загрузка:

1. На каждой странице в head подключен **menu.css**
2. В начало body добавлен **`<script src="menu.js"></script>`**
3. При загрузке страницы menu.js:
   - Подключает стили меню (если еще не подключены)
   - Загружает HTML меню из menu.html
   - Вставляет меню в начало body
   - Инициализирует функциональность

## 💡 Важно:

- Не удаляйте ссылки на **menu.css** и **menu.js** из HTML файлов
- Все три файла меню (menu.html, menu.css, menu.js) должны быть в одной папке
- При добавлении новой страницы добавьте в head и в body скрипт (см. шаблон ниже)

## 📋 Шаблон для новой страницы:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Название — Вода Добра</title>
  <link rel="stylesheet" href="menu.css">
  <link rel="stylesheet" href="style.css">
</head>
<body>

<script src="menu.js"></script>

<!-- Ваш контент здесь -->

</body>
</html>
```
